人工智能报道检索平台

操作使用手册 · 离线本地检索工具 · 仅供内部使用

一、产品简介

本平台用于检索报纸刊发的人工智能主题报道，面向日常查阅与领导阅研。全部数据存放于本机，程序离线运行，无需联网。

核心能力：

  • 栏目浏览：首页依据外部配置文件，呈现「7 个一级大类 → 二级子类」两层目录，点击即可逐级浏览。
  • 关键词检索：支持全文检索，多个关键词以空格分隔时「同时命中」。
  • 来源 / 日期筛选：可按报刊来源、刊发日期区间过滤。
  • 单篇直显：检索结果若仅命中一篇，直接展示正文与配图。
  • 详情工具：正文底部提供「原始 PDF 下载」；支持「字号调节」与「一键复制全文」。
程序启动时自动扫描数据目录下的全部文章文件，新增文章放入目录、重新打开程序即可，无需重新编译。

二、运行环境

  • 操作系统：Windows 10 及以上（64 位）。
  • 运行依赖：本机已安装 Microsoft Edge（WebView2 运行时会随 Win10 自带），用于呈现界面。
  • 网络要求：完全离线，不访问互联网。

三、快速开始

  1. 将交付文件夹（含 AI报纸检索.exe、config.json、data\ 等）整体复制到任意位置（如 D:\AI检索\）。
  2. 双击 AI报纸检索.exe。
  3. 程序自动启动并在默认浏览器中打开检索页面；同时弹出「运行中」小窗口，显示访问地址与「退出」按钮。
  4. 在浏览器中使用即可。关闭时点击小窗口的「退出」。
若浏览器未自动打开，可手动打开浏览器，访问小窗口中显示的地址（通常为 http://127.0.0.1:8765/）。

四、界面与操作

1. 栏目浏览

页面左侧为「栏目导航」，列出 7 个一级大类。点击大类名称可展开其下的二级子类；点击子类，主区域列出该栏目下的全部文章；点击文章条目进入详情页。

2. 关键词检索

在页面顶部检索框输入关键词，点击「搜索」。支持多个关键词：以空格分隔，例如 大模型 政务，表示两词需同时出现在同一篇文章中。

  • 仅命中 1 篇 → 直接展示该篇正文与配图。
  • 命中多篇 → 以目录列表展示，点击任一条目查看详情。
  • 无结果 → 提示调整关键词或筛选条件。

3. 来源与日期筛选

「来源」下拉框列出全部报刊来源；「刊发日期」可选择起、止日期。筛选可与关键词组合使用。

4. 文章详情页

  • 正文与配图：正文按段落排版，配图居中展示。
  • 字号调节：点击工具栏「小 / 中 / 大」切换正文字号。
  • 一键复制全文：将标题、来源、日期、作者与正文一并复制到剪贴板，可直接粘贴到文档或微信。
  • 下载原始 PDF：正文底部「下载原始 PDF」按钮，保存该篇报纸的原始版面文件。
  • 返回：点击「← 返回列表」回到上一级。

五、如何新增文章

无需改动程序，把文章文件放入数据目录 data\，重新打开程序即可自动加载。

1. 文章文件（JSON）

每篇文章对应一个 .json 文件，放入 data\ 目录（可直接放，也可建子文件夹）。字段说明：

字段必填说明
title是文章标题
body是正文（纯文本）。连续两个换行视为分段；单个换行转为换行符
source否报刊来源，用于「来源」筛选
date否刊发日期 YYYY-MM-DD，用于日期筛选与排序
category否一级分类，名称须与 config.json 中某大类完全一致
subcategory否二级分类，名称须与对应大类下的某子类完全一致
author否作者
summary否内容提要，列表页展示摘要
image否配图相对路径，如 img/20240101.jpg；可填字符串或数组
pdf否原始 PDF 相对路径，如 pdf/20240101.pdf
id否文章唯一标识；缺省时自动取文件名（去扩展名）
{
  "title": "人工智能赋能千行百业",
  "source": "人民日报",
  "date": "2024-01-01",
  "category": "产业应用",
  "subcategory": "智能制造",
  "author": "本报记者",
  "summary": "人工智能与制造业深度融合，催生新业态。",
  "body": "第一段内容……\n\n第二段内容……\n\n第三段内容……",
  "image": "img/20240101.jpg",
  "pdf": "pdf/20240101.pdf"
}

2. 配图与 PDF 文件

  • 将图片放入 data\img\，PDF 放入 data\pdf\。
  • 在 JSON 中以相对 data 目录的路径填写，例如 "image": "img/20240101.jpg"。
  • 未配置 image / pdf 的文章，详情页不显示对应内容，不影响检索。

3. 生效方式

新增或替换文件后，关闭并重新打开 AI报纸检索.exe 即可（程序启动时自动扫描加载）。

六、配置文件说明（config.json）

config.json 与 exe 同目录，用于定义首页两层导航结构与标题。

  • app_title：页面标题。
  • org：单位名称（右上角显示）。
  • categories：一级大类数组，每项含 name（大类名）与 sub（二级子类名数组）。
修改分类时直接编辑 config.json 中的名称（增删大类 / 子类同理）。文章的 category / subcategory 字段必须与此处名称完全一致（含字与空格），否则文章不归入对应栏目。
{
  "app_title": "人工智能报道检索平台",
  "org": "××单位 · 内部资料检索",
  "categories": [
    {"name": "政策解读", "sub": ["国家战略", "规划文件", "地方实践"]},
    {"name": "技术创新", "sub": ["大模型", "算力芯片", "前沿算法"]}
  ]
}

七、退出程序

点击「运行中」小窗口的「退出」按钮，在确认框点击「确定」即可完全关闭。

八、故障排查

现象可能原因 / 处理
双击无反应确认 Windows 10 64 位；右键「以管理员身份运行」；检查杀毒软件是否拦截
浏览器白屏确认 config.json 与 data\ 与 exe 同目录；查看小窗口地址是否正确
端口被占用另一实例已在运行，先退出旧实例；或重启电脑后重试
某篇不显示配图检查 JSON 中 image 路径与图片文件是否确实存在于 data\img\
新增文章未出现确认为 .json、含 title 与 body；确认已重新打开程序
PDF 无法下载确认 pdf 路径与文件存在；浏览器可能拦截，请允许下载

九、交付物清单

  • AI报纸检索.exe —— 独立可执行程序（双击运行，无需安装）。
  • config.json —— 导航与标题配置文件（可手动维护）。
  • data\ —— 文章数据目录（含 img\、pdf\），随用随增。
  • docs\ —— 本使用手册。
  • src\ —— 完整源代码（详见 README.md）。
